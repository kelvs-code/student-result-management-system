# Student Result Management System

## About the Project
This is a simple C++ console application that uses arrays to manage examination marks for five students.

## Features
- Accepts marks for five students.
- Validates marks between 0 and 100.
- Calculates total and average marks.
- Identifies the highest and lowest marks.
- Displays each student's pass or fail status.

## Data Structure Used
The program uses a fixed-size integer array to store students' marks.

## Technologies
- C++
- Standard Input/Output Library (`iostream`)

## How to Run
1. Download `main.cpp`.
2. Open it in a C++ IDE or compiler.
3. Compile and run the program.

Example using g++:

```bash
g++ main.cpp -o student_results
./student_results
```

On Windows Command Prompt, run:

```bash
g++ main.cpp -o student_results.exe
student_results.exe
```

## Purpose
This project demonstrates how arrays and loops can be used to store and process related data in C++.
